# Inspectors and project links

## Explore the configuration

The embedded inspectors show the configurations used to develop this repository. They are a useful way to explore the shared tooling and the rules it enables.

- [Stylelint Config Inspector](pathname:///stylelint-inspector/) shows this repository's resolved Stylelint setup, including file progress.
- [ESLint Config Inspector](pathname:///eslint-inspector/) shows the shared ESLint setup used for the plugin's TypeScript and tooling.

To change progress in your own project, use the [preset comparison](./presets.md) and [rule reference](./activate.md).

## Related projects

- [ESLint File Progress](https://nick2bad4u.github.io/eslint-plugin-file-progress-2/) is the ESLint counterpart and inspiration for this plugin. The Stylelint adapter follows its own host API and [observation boundaries](./compatibility.md).
- [ESLint Typefest](https://nick2bad4u.github.io/eslint-plugin-typefest/) provides TypeScript-focused rules for type-fest and ts-extras patterns.
- [stylelint-config-nick2bad4u](https://github.com/Nick2bad4u/stylelint-config-nick2bad4u) is the shared Stylelint configuration used in this repository.
- [Stylelint](https://stylelint.io/) documents the host linter's [configuration](https://stylelint.io/user-guide/configure/) and [CLI](https://stylelint.io/user-guide/cli/).
